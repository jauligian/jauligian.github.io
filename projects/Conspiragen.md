# Conspiragen

My Ohio State Capstone project that combines data search from the Wikipedia database with AI generation to create satirical conspiracy theory content. Uses the Google Gemini API to generate fictional theories based on real data indexed in Elasticsearch. Features a full-stack web application with a TypeScript frontend, Python backend, and Docker containerization for cloud deployment. Anything made from it is satiracle and shouldn't be taken seriously.
