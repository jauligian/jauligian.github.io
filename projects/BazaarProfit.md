# Hypixel SkyBlock Bazaar Monitor

A Java desktop application that monitors the Hypixel SkyBlock Bazaar in real-time. Fetches live product data and calculates profit metrics including profit margin, profit per hour, and a custom scoring algorithm. Features sortable data tables, configurable item filtering, a capital allocation helper, and a dark-themed UI with intelligent cell coloring to help identify the most profitable flip opportunities.
